# 开源复现材料

为提高实验可复现性，在 GitHub 平台公开与本文技术原型相关的关键复现材料。

- `01_运行环境与复现脚本/`：运行环境、推理参数与复现命令
- `02_标注样本与数据格式/`：部分标注样本（ms-swift 训练数据格式 JSON）及对应街景图像，覆盖五个诊断评级
- `03_LoRA适配器权重与加载方式/`：空间诊断阶段训练所得 LoRA adapter 权重及加载方式
- `04_完整提示词模板/`：诊断与优化阶段使用的完整 prompt templates
- `05_代表性推理结果/`：代表性案例的完整"空间诊断—空间优化"推理记录（JSON）及对应街景图像
